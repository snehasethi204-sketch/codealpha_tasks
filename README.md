# CodeAlpha Sentiment Analysis Project

## Project Description

This project uses Machine Learning to classify product reviews as Positive or Negative.

## Technologies Used

* Python
* Scikit-learn
* CountVectorizer
* Multinomial Naive Bayes
* Google Colab

## How It Works

1. The model learns from product reviews.
2. Text is converted into numerical features.
3. A Machine Learning model is trained.
4. The model predicts whether a review is Positive or Negative.

## How to Run

1. Open the CodeAlpha_Sentiment_Analysis.ipynb notebook in Google Colab.
2. Run the code cells in order.
3. Enter a review to get a sentiment prediction.

## Limitations

This is an educational project with a small dataset. Predictions may not always be accurate.
